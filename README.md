# Modern Control Learning

A step-by-step learning platform for Modern Control Systems, designed for returning learners as well as students progressing from fundamentals to advanced state-space control.

## Learning path

0. Mathematics Refresher
1. Control Systems Foundations
2. Mathematical Modeling
3. Classical Control Refresher
4. State-Space Fundamentals
5. State-Space Analysis
6. Controllability & Observability
7. State Feedback & Pole Placement
8. State Observers
9. Stability & Lyapunov Methods
10. Optimal Control / LQR
11. MATLAB & Simulink Labs
12. Advanced Topics & Projects

Every lesson follows the same learning pattern:

**Intuition → Theory → Mathematics → Visual Explanation → Worked Example → Practice → Debugging/Common Mistake → Real-World Engineering Problem → Q&A → MATLAB/Simulink → Quiz → Next Lesson**

The site is a static web application and is deployable with GitHub Pages.

## Source alignment

The project is structured around the current Modern Control course topics supplied by the learner, while prerequisite explanations and additional examples are original teaching material added to make the course accessible from a beginner/refresher level.

## Development

Open `index.html` locally or serve the repository with any static server.
